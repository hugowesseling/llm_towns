🌍 FEATURES AT A GLANCE
────────────────────────────────────────────────────────────────────────────

  Map Visualization:
    ✓ Scrollable 2D world grid (50×50 tiles)
    ✓ 11 terrain types (grass, forest, water, mountains, sand, snow, 
      swamp, roads, buildings, houses, town squares)
    ✓ Procedural tile graphics (no external sprite sheets)
    ✓ Real-time villager positions
    ✓ Town markers with entry points visible

  Interactivity:
    ✓ Arrow key scrolling (3-tile increments)
    ✓ Right-click pan (smooth dragging)
    ✓ Left-click selection (villagers & towns)
    ✓ Pause/resume (Space bar)
    ✓ Home key reset

  Character Display:
    ✓ Villagers shown as red circles
    ✓ Click to see: position, hunger, energy, social needs, current goal
    ✓ Real-time movement tracking

  Town Display:
    ✓ Towns shown as gold stars
    ✓ Click to see: name, population, economy, culture, description
    ✓ Entry/exit points visible through tile layout

⚙️ ARCHITECTURE COMPONENTS
────────────────────────────────────────────────────────────────────────────

  SimulationClient (main class)
    ├─ __init__               Initialize pygame, UI, fonts
    ├─ _connect_and_load      Fetch initial world data
    ├─ _refresh_world_data    Poll API for updates
    ├─ _update_loop           Background thread worker
    ├─ handle_events          Process keyboard/mouse input
    ├─ _select_at_position    Click detection logic
    ├─ draw                   Main render function
    ├─ _draw_map              Render tiles & entities
    ├─ _draw_sidebar          Render info panel
    └─ run                    Main game loop

  WorldViewport (viewport class)
    ├─ scroll                 Update viewport position
    ├─ screen_to_world        Convert screen coords → world
    ├─ world_to_screen        Convert world coords → screen
    └─ is_visible             Check if tile in viewport

  APIClient (network class)
    ├─ health_check           Test server connectivity
    ├─ get_world_grid         Fetch terrain grid
    ├─ get_characters         Fetch villager list
    ├─ get_towns              Fetch town list
    └─ [6+ more API methods]

  TilesetCache (graphics class)
    └─ get_tile               Fetch/cache tile surface
